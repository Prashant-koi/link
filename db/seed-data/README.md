`cso-subset.json` is generated by `scripts/build-cso-subset.mjs` from the real
[Computer Science Ontology](https://cso.kmi.open.ac.uk) (v3.5), not hand-written.
It's checked in so seeding needs no network access. Regenerate with:

```
node scripts/build-cso-subset.mjs
```

`.cso-cache.csv` (the raw ~8MB ontology download, gitignored) is reused across
runs so re-generating the subset doesn't re-download; delete it to force a
fresh download.
